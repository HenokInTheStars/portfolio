OPEN SOURCE ML · NLP

SMS Spam Detection Engine

99.24% PRECISION // 80/20 SPLIT

High-precision text classification pipeline trained to detect SMS spam with near-zero false alarms on legitimate messages.

The Problem

Aggressive spam filters frequently misroute critical transactional and personal messages to spam, eroding user trust.

What I Built

A scikit-learn NLP pipeline combining TF-IDF vectorization with Multinomial Naive Bayes, calibrated specifically for high precision.

Stack: Python Scikit-Learn TF-IDF (3,000 features) MultinomialNB (α=0.5) Pandas

Key Decision: Tuned decision parameters to prioritize 99.24% precision over maximum recall, accepting that missing ~13% of spam (87.25% recall) is vastly preferable to misflagging genuine messages.

Results: Evaluated on an 80/20 stratified split of 5,572 messages: 98.21% accuracy, 99.24% precision, 87.25% recall, 92.86% F1-score.

What I'd Improve Next: Evaluate character-level n-grams and DistilBERT embeddings to improve recall on heavily obfuscated spam texts.

STREAMLIT APP & ML

Ethiopian Airlines Flight Fare Predictor

11 MODELS BENCHMARKED

Interactive Streamlit web application predicting ticket prices (ETB) based on itinerary parameters and seasonal trends.

The Problem

Unpredictable seasonal fare volatility makes it difficult for passengers to evaluate fair booking prices.

What I Built

A Streamlit web dashboard with interactive controls giving real-time price estimates across routes and cabin tiers.

Stack: Python Streamlit LightGBM XGBoost Random Forest

Key Decision: Benchmarked 11 distinct regression algorithms rather than jumping to a deep neural net, finding LightGBM gave optimal CPU inference latency and accuracy for the Streamlit UI.

Results: Derived 18 features (including trigonometric cyclical timing encoding) and deployed functional interactive predictions.

What I'd Improve Next: Add automated web scraping to keep historical training data refreshed with current fare trends.
